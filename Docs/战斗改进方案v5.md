## 1. 回合流程(新增:先结算负面状态,再结算技能)

```
每回合:
  1.【回合初】结算双方负面状态:
     - 灼烧/中毒/沙暴/寄生种子:判定(概率)成功 → 造成固定真伤
     - 麻痹:判定成功 → 该精灵本回合行动被跳过
     - 若状态伤害击杀任意一方 → 立即判定胜负,结束战斗
  2.【锁定】双方同时锁定行动(玩家 UI / 敌方 AI)
  3.【解析】精灵球(必先手)→ 防御类 → 先制类 → 其余按行动值(±10% 扰动)
  4.【结算】技能动画/伤害/状态附加/攻防增减
  5.【回合末】攻防层剩余回合 −1、速度增减剩余回合 −1、检查胜负
```

**负面状态为固定真伤**:不吃 `strength/protect`、防御指令、铁壁等任何增减伤影响,仅按 maxHP 百分比结算。

## 3. 防御型精灵加强

### 3.1 被动「铁壁」(防御型:龟甲兽/蘑菇怪/石魔像)

- 受到**直接攻击伤害**时,额外减少 **8%** 最终伤害
- 乘法叠加,与防御指令、protect 系数**独立计算**
- 对状态真伤无效

### 3.2 防御指令(守住)强化

```
减伤 = 40% + 自身防御增益层数 × 10%(上限 70%)
```

| 自身防御层 | 减伤 |
|---|---|
| 0 | 40% |
| 1 | 50% |
| 2 | 60% |
| 3 | 70%(上限) |

- 需叠满 3 层防御才能达到原版 70%,鼓励防御型精灵先叠 buff 再开守
- 非防御型精灵用守住 = 40% 减伤(无防御层)

### 3.3 新技能(防御型干扰/续航)

| 精灵 | 移除 | 新增 | 效果 |
|---|---|---|---|
| 龟甲兽 | Rotation(×0.95) | 「潮旋」 | 普攻 ×0.95,**必中降低对方速度 1 点**(本场永久,最多 −3,可被净化解除,换人即清) |
| 蘑菇怪 | SeedBomb(×1.0) | 「寄生种子」 | 普攻 ×0.4,命中后对方每回合被吸取 **5% maxHP**(持续 3 回合,判定成功生效;每次吸取量 ≤ 自身 maxHP 的 10%) |
| 石魔像 | RockFall(与独眼巨人重复) | 「沙暴」 | 状态技(非攻击),对方每回合损失 **4% maxHP**,持续 **5 回合**,**无法被净化,敌方换人后保留** |

## 4. 状态系统 v5.1

### 4.1 状态总表

| 状态 | 判定时机 | 效果 | 持续 |
|---|---|---|---|
| ⚡ 麻痹 | 回合初 | 成功 → 跳过该精灵本回合行动 | 3 回合 |
| 🔥 灼烧 | 回合初 | 成功 → 回合末 −4% maxHP + **本回合目标造成伤害 −15%**(固定,非层数) | 3 回合 |
| ☠️ 中毒 | 回合初 | 成功 → 回合末 −6% maxHP(不可叠加) | 3 回合 |
| 🌪️ 沙暴(石魔像) | 回合初 | 成功 → 回合末 −4% maxHP,**无法被净化,敌方换人后保留** | 5 回合 |
| 🌱 寄生种子(蘑菇怪) | 回合初 | 成功 → 吸取对方 5% maxHP(每次 ≤ 自身 10%) | 3 回合 |
| 😵 混乱(史莱姆) | 行动时 | 成功 → **本回合攻击自己**(倍率 ×0.8,不吃克制) | 1 回合 |

### 4.2 统一规则

- **上状态当回合不判定**,从对方**下一回合初**开始判定
- **各层独立计算**:多次上同状态,概率取最大、各自独立计时,**效果不叠加**
  - 例:第 1 回合 35% 麻痹 + 第 2 回合 30% 麻痹 → 第 2/3/4 回合 35% 判定,第 5 回合 30% 判定,之后无
- 灼烧与中毒可同时存在,分别判定,真伤加算(每回合最多 −10% maxHP,不含沙暴/寄生种子)
- 全部为**固定真伤**,不受攻防系数/防御指令/铁壁影响

| 技能 | 原 | 新 | 说明 |

## 5. 攻防层数系统(攻击侧 2 层 / 防御侧 3 层)

### 5.1 规则

- 增益(自身攻/防↑)与减益(对方攻/防↓)按**层**计算,每层 **±0.5**
- **当前回合立即生效**,每层独立持续 **3 回合**
- **攻击侧(攻+/攻−)最多叠 2 层**;防御侧(防+/防−)最多叠 **3 层**(防御指令 70% 上限需要 3 层防御)
- 例:连续 2 回合咆哮 → 对方第 2 回合攻 −1.0(2 层),第 3 回合 −0.5(1 层),第 4 回合归零

### 5.2 生效范围

```
攻击系数 strength = 1.0 ± 0.5 × 攻击层数 ∈ [0.5, 2.0](攻击侧最多 ±2 层)
防御系数 protect  = 1.0 ± 0.5 × 防御层数 ∈ [0.5, 2.5](防御侧最多 ±3 层)
```

### 5.3 攻防技能表(数值不变,层数上限改 3)

| SporeCloud 孢子云 | 减益 | 对方攻 −0.5/层 | 蘑菇怪 |
| Focus 聚气 | 增益 | 自身攻 +0.5/层 | 龙、战蜂、食人花、独眼巨人 |

| WarCry 战吼 | 增益 | 自身攻 +0.5/层 | 独眼巨人 |
| Harden 硬化 | 增益 | 自身防 +0.5/层 | 鳐鱼、石魔像 |

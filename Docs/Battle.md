## 1. 战斗流程总览

- **同步回合制**:每回合双方同时锁定行动(玩家选操作、敌方 AI 决策),互相不可见
- **回合序**:
```
每回合:
  1.【回合初】结算双方负面状态(灼烧/中毒/沙暴/种子真伤 + 灼烧减伤标记 + 麻痹判定)
     → 状态击杀 → 立即判定胜负
  2.【锁定】双方同时锁定行动
  3.【解析】精灵球(必先手)→ 防御类 → 先制类 → 其余按行动值(±10% 扰动)
  4.【结算】技能动画/伤害/状态附加/攻防增减
  5.【回合末】攻防层/速度层剩余回合 −1、检查胜负
```
- **负面状态为固定真伤**:不吃 strength/protect、防御指令、铁壁
- **玩家操作**:技能 / 道具 / 切换精灵(腰间)/ 逃跑(Boss 不可)

## 2. 精灵基础属性

### 2.1 定位数值(10 只精灵)

| 定位 | baseHP | hpPerLevel | baseAttack | atkPerLevel | 速度区间 | 精灵 |
|---|---|---|---|---|---|---|
| 🗡️ 攻击型 | **47** | 4.7 | 7 | **0.60** | 8~12 | 龙、眼魔、食人花、独眼巨人 |
| ⚖️ 均衡型 | **52** | 5.25 | 6 | **0.52** | 6~10 | 战蜂、鳐鱼、史莱姆 |
| 🛡️ 防御型 | **63** | 6.3 | 5.5 | **0.48** | 4~8 | 龟甲兽、蘑菇怪、石魔像 |

### 2.2 属性公式

```
基础HP   = baseHP + 等级 × hpPerLevel × 个体g_hp(±10%)
基础攻击 = baseAttack + 等级 × atkPerLevel × 个体g_atk(±5%)
行动值    = Random(速度区间) + 等级 × 0.2(战斗时 ±10% 扰动,可叠速度层)
```

- 升级:`maxHP += hpPerLevel × g_hp`,`attack += atkPerLevel × g_atk`,升级全回复 + 能量回满
- 死亡标志 `isDead`:HP ≤ 0 同步,仅复活药水可解除

### 2.3 防御型被动「铁壁」

- 防御型定位(baseHP ≥ 60)精灵受到**直接攻击伤害**时额外减少 **8%**(乘法叠加,独立计算)
- 对状态真伤无效

## 4. 技能类型与能量消耗（v6）

- 精灵初始 **15 点能量**,能量是持久资源(跨战斗不恢复)
- **升级 / 捕捉入队回满能量和血量**;能量药剂恢复出战精灵 **10 点能量**

| 类型 | 能量消耗 | 定位 |
|---|---|---|
| 大招 Ultimate | **5** | 爆发(唯一吃克制) |
| 普攻 Basic | **2** | 主输出 |
| 先制 Priority | **2** | ×0.75,必定先手 |
| 增益 Buff | **2** | 自身攻/防 +层 |
| 减益 Debuff | **2** | 对方攻/防 −层 |
| 净化 Cleanse | **2** | 清除对方增益层+速度减益 + 附加效果 |

## 5. 状态机制

### 5.1 统一规则

- **上状态当回合不判定**,从对方**下一回合初**开始判定
- **各层独立计算**:多次上同状态,概率取最大、各自独立计时、**效果不叠加**
  - 例:第 1 回合 35% 麻痹 + 第 2 回合 30% 麻痹 → 第 2/3/4 回合 35%,第 5 回合 30%,之后无
- **全部为固定真伤**,不受攻防系数/防御指令/铁壁影响

## 6. 攻防层数系统

### 6.1 规则

- 增益(自身攻/防↑)与减益(对方攻/防↓)按**层**计算,每层 **±0.5**
- **当前回合立即生效**,每层独立持续 **3 回合**
- **攻击侧(攻+/攻−)最多 2 层;防御侧(防+/防−)最多 3 层**
- 例:连续 2 回合咆哮 → 对方第 2 回合攻 −1.0(2 层),第 3 回合 −0.5(1 层),第 4 回合归零

### 6.2 生效范围

```
攻击系数 strength = 1.0 ± 0.5 × 攻击层 ∈ [0.5, 2.0]
防御系数 protect  = 1.0 ± 0.5 × 防御层 ∈ [0.5, 2.5]
```

| 技能 | 类型 | 效果 | 使用者 |


## 7. 伤害公式

```
基础伤害 = 攻击力 × strength × 技能倍率
蓄能冲撞:自身有攻增益层 → 倍率 +0.2
大招追加:克制 ×1.8 / 被克 ×0.8
灼烧减伤:攻击者本回合灼烧生效 → ×0.85
防御指令:减伤 = 40% + 防御层×10%(上限 70%)
最终伤害 = 基础伤害 / max(0.5, protect)
铁壁:防御型 ×0.92
等级压制:攻击方每高 1 级 → 伤害 ×(1 + 0.05 × 等级差),上限 ×2.0(差 20 级封顶)
```

## 10. 楼层与等级

```
普通野怪 = max(1, 3 × 楼层 + rand(1, 5))
Boss 队伍 = 野怪等级 + rand(4, 7)
玩家从 0 层向 9 层爬(每层都有 Boss,击败后楼梯解锁)
Boss 队伍数量 = 2 + floor/2(0,1→2 / 2,3→3 / 4,5→4 / 6,7→5 / 8,9→6)
```

| 楼层 | 野怪 | Boss 等级 | Boss 数量 |
|---|---|---|---|
| 0 | 1~4 | 5~10 | 2 |
| 1 | 4~7 | 8~14 | 2 |
| 2 | 7~10 | 11~17 | 3 |
| 3 | 10~13 | 14~20 | 3 |
| 4 | 13~16 | 17~23 | 4 |
| 5 | 16~19 | 20~26 | 4 |
| 6 | 19~22 | 23~29 | 5 |
| 7 | 22~25 | 26~32 | 5 |
| 8 | 25~28 | 29~35 | 6 |
| 9 | 28~31 | 32~38 | 6 |

**通关**:击败第 9 层最终 Boss → 弹出通关结束语 → 数秒后自动保存并返回主菜单

**升级所需经验**:`20 × 当前等级 + 30`(溢出结转)
**击败经验**:普通 `55 × 敌方等级 + 30`;Boss `55 × 队伍等级总和 + 30 × 数量`;出战 100%、腰间其他 20%
**捕捉经验**:被捕捉精灵 70% + 最后出战 70%,其余腰间 30%

### 11.1 捕捉

```
Ultra 必中;其他:捕捉率 = 球基础率 × 血量档位 × 等级惩罚
```

| 球 | 价格 | 基础率 | 等级惩罚/级 |
|---|---|---|---|
| Chip | 20r | 28% | −2.0% |
| Normal | 50r | 46% | −1.5% |
| Great | 100r | 64% | −1.0% |
| Ultra | 200r | 100%(必中) | 无 |

- 血量档位:≥60% ×0.35 / 30~60% ×1.0 / <30% ×1.6;clamp(3%, 90%)
- 捕捉失败 → 敌方本回合行动照常(无无伤机制)

### 11.2 逃跑 / 全灭

- 逃跑:敌方必定先行动一次,存活则成功(无惩罚)
- 全灭:腰间精灵全部阵亡 → 回地牢(有复活药水或金币 ≥80);否则 Game Over
- 战斗队伍 = 腰间精灵
